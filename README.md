# UNDERLAYER — v0.4

Roblox-прототип совместных раскопок на мрачной планете с личной коллекцией растущих малышей.

**Запуск:** скачай проект, открой `Underlayer.rbxlx` в Roblox Studio и нажми **Play**. Карта уже встроена в файл и видна до Play. Для обычного теста в Studio не нужны публикация и API-доступ.

Полная инструкция: [START_HERE_RU.md](START_HERE_RU.md).

- Три слоя раскопок, ресурсы, продажа и улучшения инструментов.
- Опасные выбросы и потеря 25% несданного при гибели.
- Шесть малышей, пять стадий роста, 3D-просмотр коллекции.
- Бесплатные спутники; Robux-помощь, дополнительные места, конкретные малыши и яйца подготовлены под ID владельца.
- Личный прогресс сохраняется через DataStore; раскопки общие в пределах сервера.

Это v0.2 с простыми моделями. Исправлен запуск при недоступном DataStore; HUD стал компактнее. Полный запуск в Roblox Studio здесь недоступен. Доступные проверки и ограничения: [QA.md](QA.md).

## Структура

- `Underlayer.rbxlx` — place для Studio.
- `src/` — исходники Lua.
- `default.project.json` — проект Rojo.
- `build.py` — сборка place с Python 3 и системной `liblua5.4`.
- `verify.py` — проверки с Python 3 и системной `liblua5.4`.

Платные товары отключены до заполнения `src/Config.lua` или модуля Config в Studio. После изменения исходников запусти `python3 build.py`, чтобы пересобрать place.

## Исправления v0.2

- Карта, лагерь, освещение, спавн и 702 блока находятся в самом place-файле.
- Ошибка доступа к DataStore больше не останавливает создание мира.
- В Studio по умолчанию работает временный профиль без внешних API.
- Небольшой HUD в углу; меню и магазин открываются по кнопке.
- Проверен сценарий отказа самого `GetDataStore`, а не только сохранения.

Если открыт старый файл, останови Play и открой заново скачанный `Underlayer.rbxlx`. Обновление GitHub не обновляет уже открытый в Studio файл автоматически.

## Большая лунная карта v0.3

- Равнина 3072 × 3072 studs, примерно в 173 раза больше площади старой карты 210 × 260.
- Двенадцать участков раскопок: 2160 блоков, 3 слоя. Обычный лунный грунт между участками тоже вскрывается и добывается.
- Двенадцать крупных кратеров с покатыми стенками, 96 дальних горных массивов, небольшие валуны, лунный лагерь с жилым модулем, антенной и грузом.
- Двенадцать полевых пунктов сдачи плюс терминал главного лагеря.
- Shift — бег, указатель ближайшего участка под HUD.
- Карта полностью встроена в place. Layout.lua — общий источник размеров и координат.

Визуальное направление вдохновлено просторными лунными локациями Moon Sweepers; ассеты и код этой игры не используются. Это стилизованная карта из геометрии Roblox, а не точная копия и не Terrain-карта.

## Обучение и малыши v0.4

Новый игрок начинает в учебном помещении. Следуй текущему заданию и жёлтой метке: стойка → пыль → скребок → камень → кокон → терминал → шлюз. После выхода в экспедицию доступны заказ на очистку и ремонт генератора. Кнопка «В учебный отдел» возвращает в безопасное помещение.

Инструмент виден в руке, малыши имеют отдельные головы, морды, лапы, когти и особенности каждого вида. Это модели из геометрии Roblox.

Полный согласованный дизайн и точные границы реализации: [GAME_DESIGN_RU.md](GAME_DESIGN_RU.md). Транспорт, перелёты, пещеры и законченная сюжетная цепочка пока не реализованы.

## Исправления грунта и света v0.5

Обычная поверхность LunarRegolith теперь доступна для добычи после обучения. При первом ударе большая плита делится на 48 блоков трёх слоёв. Строения, оборудование, кратерные скалы и прочное нижнее основание не добываются. Первый удар вскрывает плиту, последующие снимают слои. Высота прыжка 10 studs позволяет выбраться с нижнего основания на поверхность; кнопка возврата в учебный отдел остаётся доступной.

Направленный свет настроен на 10:30, сила учебных ламп уменьшена. Фактическое изображение в Roblox Studio требует проверки. Концепт нового Пылика пока не является импортированным 3D-мешем.
