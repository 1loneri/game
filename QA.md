# Проверка v0.3

Проверено 29 октября 2026 года:

- Все 6 Lua-файлов успешно компилируются парсером Lua 5.4. Использован общий синтаксис Lua, без расширений синтаксиса Luau. Roblox API не исполнялись.
- Проверены пороги уровня, стадии роста, состав яиц и сумма вероятностей 100%.
- На имитации DataStore проверены сохранение, повторная квитанция без повторной выдачи, снятие блокировки при выходе, отказ загрузки при активной чужой сессии, отказ загрузки при сбое публичного сохранения, временный Studio-профиль без покупок и отказ записи после потери владения профилем.
- XML place разбирается; каждый встроенный скрипт точно совпадает с исходником. Все referent уникальны.

Не проверено в Roblox Engine: импорт place, физика/прохождение карты, ракурсы камеры, интерфейс и анимации, сетевой тест с двумя игроками, реальный DataStore, Roblox-платежи и PolicyService. Для этого нужен Roblox Studio. Статические и имитированные проверки не подтверждают эти сценарии.

Перед продажами необходимо провести перечисленные сценарии в опубликованной тестовой копии. ID товаров по умолчанию 0; платные покупки не подключены.

## Регрессия пустого мира

- На имитации API воспроизведено исключение при самом вызове GetDataStore в неопубликованной игре. Модуль теперь загружается, Studio получает временный профиль.
- Обычный локальный запуск вообще не вызывает GetDataStore. При отказе API в публичной игре по-прежнему нет сброса существующего прогресса.
- В XML находятся 825 закреплённых физических объектов, включая спавн и 702 блока. Для каждого проверены положительные размеры и CFrame.
- World.Build повторно использует уже встроенный мир и его интерактивные объекты. Эта ветка проверяется адаптером при сборке.
- Сервер создаёт/подключает мир раньше профилей. Клиент выводит понятную ошибку после тайм-аута, если серверная логика всё-таки не запустилась.
- Визуальная проверка и физика в настоящем Roblox Studio здесь не выполнялись.

## Большой лунный мир v0.3

- Проверены размеры равнины 3072 × 3072, двенадцать участков внутри границ, координаты трёх слоёв и соответствие Layout.lua всем генераторам.
- Проверены 2256 плит поверхности, 2160 добываемых блоков, двенадцать полевых пунктов сдачи, 96 дальних горных массивов, сегменты кратеров и 72 ступени выхода.
- Полосы лестниц не перекрыты залежами.
- Сохранён тест отказа DataStore: он не мешает загрузке заранее встроенного мира.
- Проверены синтаксис семи различных Lua-модулей, XML, положение спавна, закрепление геометрии и соответствие встроенных скриптов исходникам.
- Физическое прохождение, реальная визуализация неба и кратеров, сетевой запуск и FPS в Roblox Engine здесь не проверялись. Геометрия из 6191 физических объектов требует проверки производительности на целевых устройствах.

- Для большой карты включён StreamingEnabled: минимальный радиус 128, целевой 512 studs. Проверены соответствующие параметры в place.

## Обучение и модели v0.4

- Проверены синтаксис, соответствие скриптов в place, геометрия помещения, стойка, шлюз и фундамент.
- В адаптере реально вызван PetVisual.Build для шести видов на стадиях 1 и 50: не менее 40 отдельных элементов, отдельные голова и морда, 4 лапы, 12 когтей, два глаза, увеличение взрослых форм. Это проверка сборки, не проверка красоты или движка.
- Новый профиль начинается без питомца с учебным шагом 0.
- Проверки настоящего EquipTool, ProximityPrompt, меток при StreamingEnabled, прохождения урока и физики комнаты в Roblox Studio здесь не выполнялись.
- В учебной комнате один общий участок; массовое одновременное обучение и восстановление исчерпанного участка требуют отдельной реализации перед релизом.
