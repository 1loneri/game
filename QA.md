# Проверка v0.1

Проверено 29 октября 2026 года:

- Все 6 Lua-файлов успешно компилируются парсером Lua 5.4. Использован общий синтаксис Lua, без расширений синтаксиса Luau. Roblox API не исполнялись.
- Проверены пороги уровня, стадии роста, состав яиц и сумма вероятностей 100%.
- На имитации DataStore проверены сохранение, повторная квитанция без повторной выдачи, снятие блокировки при выходе, отказ загрузки при активной чужой сессии, отказ загрузки при сбое публичного сохранения, временный Studio-профиль без покупок и отказ записи после потери владения профилем.
- XML place разбирается; каждый встроенный скрипт точно совпадает с исходником. Все referent уникальны.

Не проверено в Roblox Engine: импорт place, физика/прохождение карты, ракурсы камеры, интерфейс и анимации, сетевой тест с двумя игроками, реальный DataStore, Roblox-платежи и PolicyService. Для этого нужен Roblox Studio. Статические и имитированные проверки не подтверждают эти сценарии.

Перед продажами необходимо провести перечисленные сценарии в опубликованной тестовой копии. ID товаров по умолчанию 0; платные покупки не подключены.
