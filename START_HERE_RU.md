# UNDERLAYER — Roblox-прототип v0.2

Мрачная планета, общие раскопки и личная коллекция растущих малышей.

## Запуск за минуту

1. Распакуй архив.
2. Открой Roblox Studio → File → Open from File → **Underlayer.rbxlx**.
3. Нажми **Play**. Карта уже находится в файле: лагерь и залежи видны до Play. Обычный запуск не требует публикации.
4. Выйди из лагеря вперёд к серым залежам. Наведи курсор на блок и удерживай ЛКМ.
5. Вернись к левому терминалу: **E** сдаёт ресурсы. Правый верстак: **E** покупает следующее улучшение.
6. Снизу кнопки «Малыши», «Магазин» и «Журнал». **B** тоже открывает коллекцию. Камера вращается правой кнопкой мыши, колёсико приближает.

На сенсорном экране копай кнопкой «Копать», целясь крестиком по центру. Мобильный интерфейс требует проверки на реальных устройствах.

## Уже реализовано

- Общая зона из 702 разрушаемых блоков: пыль, камень, кристальная корка.
- Рюкзак, монеты и опыт. Щётка → скребок (140 монет) → бур (650 монет).
- Предупреждение красным кругом за 2,5 секунды до опасного выброса. Урон 38.
- Гибель отнимает 25% несданных ресурсов с округлением вверх. Всё остальное сохраняется.
- Пылик с начала игры; Мохлик и Кристик находятся при раскопках. Шанс кокона 7,5% на блок, вид равновероятен. Повторы дают фрагменты.
- Каждый взятый с собой малыш растёт на 0,14 уровня за очищенный блок до уровня игрока, максимум 50. Новый малыш всегда начинает с 1.
- Пять стадий внешности: уровни 1 / 6 / 15 / 30 / 50. Размер увеличивается между стадиями. Просмотр всех форм в коллекции.
- Пять фрагментов автоматически открывают светлый окрас спутника. В этой версии он применяется без отдельной кнопки.
- Один активный малыш бесплатно; коллекция не ограничена. Бесплатные малыши не добывают ресурсы.
- Пропуск помощи: каждый активный спутник наносит 1 урон ближайшей доступной залежи раз в 3 секунды. Пропуск мест: три активных спутника.
- Три особых малыша: Нова, Умбра, Сол. Можно купить конкретного или яйцо: 60% / 30% / 10% соответственно. Механического преимущества сверх общего пропуска помощи у них нет.
- Повторная покупка конкретного малыша или повтор из яйца даёт фрагмент окраса. Деньги не пропадают без награды.
- После 90 общих очищенных блоков появляется капсула с Кристиком и 100 опыта. Каждый игрок может забрать её награду один раз за сервер.
- Каждые 10 минут восстанавливаются до трёх полностью очищенных колонок, если рядом нет игрока.

## Сохранения

Опубликованная игра использует DataStore: монеты, опыт, инструмент, рюкзак, малыши, рост, выбор спутников, яйца и обработанные покупки. Автосохранение каждые 45 секунд, при выходе и закрытии сервера. Есть блокировка одновременного открытия профиля на разных серверах. При недоступном сохранении публичный сервер не начинает новую временную игру поверх старого профиля.

В Studio по умолчанию используется временный профиль: `StudioPersistence = false`. DataStore и PolicyService не запрашиваются. Об этом написано в маленькой панели сверху слева. Покупки отключены, прогресс тестового запуска не сохраняется.

Для проверки сохранений опубликуй **отдельную тестовую копию** в своём аккаунте. В Config установи `StudioPersistence = true`. В настройках игры включи Security → Enable Studio Access to API Services. Названия меню могут отличаться в локализации Studio.

Сама карта, счётчик общих раскопок и награды серверной капсулы между серверами не сохраняются. На новом сервере начинается новая экспедиция. Это текущая граница прототипа.

## Подключение Robux-покупок

По умолчанию все ID равны **0**, и магазин сообщает «Не настроено». Никаких подставных ID и тестовых списаний нет.

После публикации создай товары в Creator Dashboard и внеси ID в **ReplicatedStorage → Underlayer → Config**:

| Поле | Тип товара | Что даёт |
| --- | --- | --- |
| HelpPass | Game Pass | Автоматическая помощь спутников |
| SlotsPass | Game Pass | Всего 3 активных спутника |
| EggProduct | Developer Product | Одно яйцо в инвентарь |
| DirectProducts.Nova | Developer Product | Конкретная Нова / фрагмент при повторе |
| DirectProducts.Umbra | Developer Product | Конкретная Умбра / фрагмент при повторе |
| DirectProducts.Sol | Developer Product | Конкретный Сол / фрагмент при повторе |

Используй разные ID, принадлежащие именно этой игре. Цены задавай в Creator Dashboard: клиент получает их от Roblox, окончательная цена показывается в стандартном окне покупки. Пропуски покупаются один раз, товары — повторно.

Яйцо сначала зачисляется в инвентарь по подтверждённой квитанции, затем открывается отдельной кнопкой. Зачисление и отметка квитанции записываются одной операцией DataStore; повторная доставка квитанции не должна выдавать награду снова. Открытие яйца также сохраняется до показа результата.

PolicyService проверяется сервером при входе: если случайные платные предметы запрещены или проверка не удалась, покупка и открытие яиц блокируются. Конкретные малыши остаются альтернативой. Все шансы видны перед покупкой, обмена предметами в игре нет. Не включай внешние продажи продукта-яйца без отдельной проверки ограничений канала продаж.

Перед реальными продажами обязательно проверь покупки, повторную доставку квитанций, переподключение и ограничения аккаунтов в опубликованной тестовой игре. Эти сценарии нельзя подтвердить здесь без Roblox Studio и аккаунта владельца.

## Что это за версия

Это играбельная техническая основа, а не законченная коммерческая игра. Малыши и мир собраны из простых объёмных фигур; моделей из CRACK, Moon Sweepers или Pokémon нет. Стадии появляются при пересечении порогов; размер меняется небольшими шагами во время добычи.

Опасности сейчас представлены выбросами; вражеских NPC, отдельного ИИ монстров, техники, звуков, большого подземелья и индивидуальной базы пока нет. Все малыши с пропуском помогают одним способом. Клавиатура/мышь — основной способ управления; геймпад отдельно не настроен.

## Проверка вдвоём

В Studio запусти локальный сервер с двумя игроками. Разрушенный блок должен исчезнуть у обоих. Ресурсы и опыт получает тот, кто нанёс последний удар. Монеты и коллекции у каждого свои. Попробуй заполнить рюкзак, сдать добычу, купить скребок, пережить выброс, погибнуть и забрать капсулу каждым игроком.

## Исходники

`src/` содержит шесть читаемых Lua-файлов. `default.project.json` — структура для Rojo. `build.py` пересобирает XML-place из исходников с Python 3 и liblua5.4. Геометрия лагеря берётся из World.lua через адаптер tools/capture_world.lua. Адаптер нужен только для сборки и не является симулятором Roblox Engine. Файлы `QA.md` и `verify.py` описывают и выполняют доступные автоматические проверки; Roblox Engine ими не заменяется.

## Если был открыт старый проект

Останови Play, закрой старый place и открой новый `Underlayer.rbxlx` из свежего архива GitHub. В Explorer до запуска должны быть Workspace → UnderlayerWorld → Deposits и CampSpawn. Это готовая геометрия, а не результат выполнения серверного скрипта.
